# Ad-Hoc Commands Explanation

1. **Ad-Hoc Command چیست؟**
   دستورات سریع و یکباره‌ای هستند که بدون نیاز به نوشتن Playbook، یک Task را روی هاست‌ها اجرا می‌کنند. برای تست، عیب‌یابی و تغییرات سریع استفاده می‌شوند. تفاوت آن با Playbook در این است که Ad-Hoc فقط یک Task را اجرا می‌کند، اما Playbook می‌تواند چندین Task را به صورت ساختاریافته و قابل استفاده مجدد اجرا کند.

2. **ساختار:**
   `ansible <hosts> -m <module> -a "<arguments>" [options]`
   - `<hosts>`: گروه یا هاست مقصد (مثلاً all).
   - `-m`: نام ماژول.
   - `-a`: آرگومان‌های ماژول.
   - `-i`: مسیر inventory.
   - `-u`: نام کاربری.
   - `--become`: استفاده از sudo.
