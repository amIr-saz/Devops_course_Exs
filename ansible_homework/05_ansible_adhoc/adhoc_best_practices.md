# Ad-Hoc Best Practices

1. **چه زمانی از ad-hoc استفاده کنیم؟**
   برای Tasks سریع، یکباره و تست‌های فوری (مثلاً ری‌استارت کردن یک سرویس یا کپی کردن یک فایل روی چند سرور).

2. **چه زمانی باید Playbook بنویسیم؟**
   برای Tasks پیچیده، چند مرحله‌ای، یا کارهایی که نیاز به اجرای مجدد (Idempotent) و نگهداری طولانی‌مدت دارند.

3. **Best Practices:**
   - همیشه از `-m` و ماژول‌های مناسب استفاده کنید، نه `shell` یا `command` مگر در ضرورت.
   - از `--check` برای تست قبل از اجرا استفاده کنید.
   - برای کارهای تکراری همیشه به فکر تبدیل آن به Playbook باشید.
