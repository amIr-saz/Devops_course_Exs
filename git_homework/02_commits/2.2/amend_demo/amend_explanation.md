# توضیح دستور git commit --amend

دستور `git commit --amend` برای اصلاح **آخرین کامیت** استفاده می‌شود. گاهی اوقات ممکن است فراموش کنیم یک فایل را به کامیت اضافه کنیم، یا در پیام کامیت غلط املایی داشته باشیم.

## چه زمانی از Amend استفاده می‌کنیم؟
1. **فراموش کردن یک فایل:** اگر یک فایل را Stage کنید و سپس با `--amend` کامیت کنید، آن فایل به آخرین کامیت اضافه می‌شود و هش (Hash) کامیت تغییر می‌کند، بدون اینکه یک کامیت جدید در تاریخچه ثبت شود.
2. **اصلاح پیام کامیت:** اگر پیام کامیت را اشتباه نوشته باشیم، با `git commit --amend -m "New Message"` می‌توانیم آن را اصلاح کنیم.

**نکته مهم:** اگر کامیت مورد نظر را قبلاً Push کرده‌اید، استفاده از Amend خطرناک است چون تاریخچه را تغییر می‌دهد و باعث ایجاد تداخل برای سایر همکاران می‌شود. Amend فقط برای کامیت‌های محلی (Local) توصیه می‌شود.
