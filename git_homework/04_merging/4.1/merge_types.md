# انواع مرج (Merge) در Git

## Fast-Forward Merge
این نوع مرج زمانی اتفاق می‌افتد که شاخه‌ای که می‌خواهید مرج کنید (مثلاً feature)، از آخرین کامیت شاخه فعلی (main) جلوتر رفته باشد و در شاخه اصلی هیچ کامیت جدیدی ثبت نشده باشد.
در این حالت، Git به جای ایجاد یک کامیت جدید (Merge Commit)، فقط اشاره‌گر شاخه `main` را به جلو حرکت می‌دهد و تاریخچه خطی باقی می‌ماند. این تمیزترین نوع مرج است.
