# انواع مرج (Merge) در Git
## Three-Way Merge (مرج عادی)
اگر همزمان با کار روی شاخه feature، شاخه main هم تغییراتی داشته باشد، Fast-Forward ممکن نیست. در این حالت Git یک «کامیت ادغام» (Merge Commit) جدید ایجاد می‌کند که دو تاریخچه را به هم متصل می‌کند.

## Merge بدون Conflict
اگر دو شاخه فایل‌های جداگانه‌ای را تغییر داده باشند (مثلاً شاخه A فایل A را و شاخه B فایل B را)، Git به طور خودکار هر دو تغییر را می‌پذیرد و Merge بدون هیچ خطایی انجام می‌شود.
