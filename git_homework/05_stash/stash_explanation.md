# توضیح Stash در Git

دستور `git stash` برای **ذخیره موقت تغییرات** استفاده می‌شود. وقتی وسط کار روی یک ویژگی هستید و ناگهان باید به شاخه دیگری بروید (مثلاً برای رفع فوری یک باگ)، می‌توانید تغییرات فعلی را Stash کنید تا پوشه کاری تمیز شود.

## تفاوت `pop` و `apply`
- **`git stash apply`:** آخرین Stash را روی پوشه کاری اعمال می‌کند، اما **آن را از لیست Stashها حذف نمی‌کند**. (می‌توانید در صورت نیاز دوباره از آن استفاده کنید).
- **`git stash pop`:** آخرین Stash را اعمال می‌کند و **از لیست Stashها حذف می‌کند**. (ترکیب apply + drop).

## چرا فایل‌های Untracked (ردیابی نشده) داخل Stash نمی‌روند؟
به صورت پیش‌فرض، `git stash` فقط تغییرات فایل‌هایی را ذخیره می‌کند که Git آن‌ها را می‌شناسد (یعنی حداقل یک بار add شده باشند). فایل‌های جدیدی که هنوز add نشده‌اند (Untracked) نادیده گرفته می‌شوند. برای اینکه این فایل‌ها هم Stash شوند، باید از دستور `git stash -u` (یا `--include-untracked`) استفاده کنید.
