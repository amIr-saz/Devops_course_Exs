# همکاری (Collaboration) در GitHub

## افزودن Collaborator
در تنظیمات ریپوی گیت‌هاب (Settings > Collaborators) می‌توانید سایر افراد را اضافه کنید تا دسترسی Push داشته باشند.

## تفاوت git fetch و git pull
- **`git fetch`:** فقط تغییرات جدید را از ریموت دانلود می‌کند، اما روی فایل‌های لوکال شما هیچ تغییری اعمال نمی‌کند. (برای بررسی تغییرات قبل از ادغام مناسب است).
- **`git pull`:** تغییرات را دانلود می‌کند و بلافاصله آن‌ها را با شاخه لوکال **مرج** می‌کند (ترکیب fetch + merge). اگر تغییرات روی یک فایل مشترک باشد ممکن است Conflict ایجاد شود.

## تنظیمات Pull Behavior
- `git config pull.rebase false`: پیش‌فرض است. Merge معمولی انجام می‌شود (یک Merge Commit ایجاد می‌شود).
- `git config pull.rebase true`: تغییرات لوکال را روی ریموت Rebase می‌کند (تاریخچه خطی می‌شود).
- `git config pull.ff only`: فقط Fast-Forward را مجاز می‌داند و اگر نیاز به Merge باشد متوقف می‌شود.
