این پروژه یک قالب (Template) اولیه است که برای تمرین کار تیمی و آشنایی با چرخه‌ی کاری گیت‌هاب (Fork، Clone، Pull، Push و Pull Request) طراحی شده است. هدف آن نشان دادن اهمیت یک README خوب برای مستندسازی پروژه است.
