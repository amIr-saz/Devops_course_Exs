# توضیح دستورات git diff

دستور `git diff` برای مشاهده تغییرات استفاده می‌شود و سه حالت مهم دارد:

1. **`git diff` (بدون آرگومان):**
   تغییرات موجود در **پوشه کاری (Working Directory)** را نسبت به **ناحیه Staging** نشان می‌دهد. یعنی تغییراتی که هنوز `git add` نشده‌اند.

2. **`git diff --staged` (یا `--cached`):**
   تغییرات موجود در **ناحیه Staging** را نسبت به **آخرین کامیت** نشان می‌دهد. یعنی تغییراتی که `git add` شده‌اند و آماده کامیت هستند.

3. **`git diff HEAD`:**
   تمام تغییرات (هم Staged و هم Unstaged) را نسبت به **آخرین کامیت** نشان می‌دهد. در واقع تفاوت بین وضعیت فعلی فایل‌ها با آخرین کامیت ثبت شده.

**فیلتر کردن:** با اضافه کردن نام فایل (مثلاً `git diff file1.txt`) می‌توانید فقط تغییرات یک فایل خاص را ببینید.
