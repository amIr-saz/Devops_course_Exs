# حالت Detached HEAD

## مفهوم Detached HEAD
در حالت عادی، `HEAD` به یک شاخه (Branch) اشاره می‌کند (مثلاً `main`). اما اگر با دستور `git checkout <commit-hash>` یا `git checkout HEAD~1` به یک کامیت خاص در گذشته بروید، `HEAD` دیگر به شاخه اشاره نمی‌کند و مستقیماً به آن کامیت اشاره می‌کند. به این حالت **Detached HEAD** (HEAD جدا شده) می‌گویند.

## چرا اتفاق می‌افتد؟
برای بررسی کدهای قدیمی، تست کردن یک نسخه خاص، یا پیدا کردن منبع یک باگ.

## خطر آن چیست؟
اگر در حالت Detached HEAD تغییراتی ایجاد کنید و کامیت بزنید، آن کامیت به هیچ شاخه‌ای متصل نیست. اگر از این حالت خارج شوید (مثلاً به main بروید)، آن کامیت گم می‌شود و هیچ راهی برای پیدا کردنش ندارید (مگر با Reflog).

## چگونه از Detached HEAD خارج شویم؟
- برای بازگشت بدون ذخیره تغییرات: `git switch main`
- برای ذخیره تغییرات و ساخت یک شاخه جدید: `git switch -c new-branch-name` یا `git branch new-branch-name` و سپس `git switch main`.
