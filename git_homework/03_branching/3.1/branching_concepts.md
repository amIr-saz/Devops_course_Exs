# مفاهیم Branching در Git

## Branch (شاخه)
شاخه یک خط توسعه مستقل است. با ایجاد شاخه، می‌توانید روی یک ویژگی جدید کار کنید یا یک باگ را برطرف کنید، بدون اینکه بر روی شاخه اصلی (Main) تغییری ایجاد شود. این کار اجازه می‌دهد چند نفر همزمان روی بخش‌های مختلف پروژه کار کنند.

## Master/Main (شاخه پیش‌فرض)
شاخه‌ای است که به صورت پیش‌فرض هنگام `git init` ایجاد می‌شود. در استانداردهای جدید نام آن `main` و در قدیم `master` بود. این شاخه معمولاً شامل کدهای پایدار و آماده انتشار است.

## HEAD
`HEAD` یک اشاره‌گر (Pointer) است که به **آخرین کامیت در شاخه‌ای که در حال حاضر روی آن هستیم** اشاره می‌کند. در واقع به Git می‌گوید "من الان کجای تاریخچه هستم". اگر شاخه خود را تغییر دهید (با `git switch`)، HEAD نیز به آخرین کامیت آن شاخه جدید منتقل می‌شود.
