# مدیریت شاخه‌ها (Branch Management)

## تغییر نام شاخه
با دستور `git branch -m old-name new-name` می‌توانید نام یک شاخه را تغییر دهید.

## حذف شاخه: تفاوت -d و -D
- **`git branch -d <branch-name>` (Safe Delete):** این دستور فقط شاخه‌هایی را حذف می‌کند که تغییرات آن‌ها **مرج شده باشد** (یعنی با شاخه اصلی ادغام شده باشند). اگر شاخه دارای کامیت‌های مرج‌نشده باشد، Git از حذف آن جلوگیری می‌کند تا اطلاعات از دست نرود.
- **`git branch -D <branch-name>` (Force Delete):** این دستور شاخه را **به زور** حذف می‌کند، حتی اگر تغییرات آن با شاخه دیگر مرج نشده باشد. استفاده از این دستور باید با احتیاط انجام شود، زیرا ممکن است کدهای ذخیره‌نشده از بین بروند.

## جابه‌جایی با فایل‌های Untracked
اگر فایل‌هایی در پوشه داشته باشید که هنوز به Git اضافه (Track) نشده‌اند، با تغییر شاخه (git switch) آن فایل‌ها همراه شما به شاخه جدید می‌آیند و پاک نمی‌شوند.
